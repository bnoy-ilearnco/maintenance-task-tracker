Firebase setup needed

Open this file in a text editor and replace the placeholder object near the top of the script with your Firebase web app config.

const firebaseConfig = {
  apiKey: "PASTE_API_KEY",
  authDomain: "PASTE_AUTH_DOMAIN",
  projectId: "PASTE_PROJECT_ID",
  storageBucket: "PASTE_STORAGE_BUCKET",
  messagingSenderId: "PASTE_SENDER_ID",
  appId: "PASTE_APP_ID"
};

Firestore must be enabled for the project. The default admin password is admin123; change it from Settings after first login.
